# MT4 Position Sizer & Basket Manager

MetaTrader 4 version of the Position Sizer & Basket Manager.

## Main features

- Position sizing by percentage or fixed-money risk
- Visual stop-loss calculation line
- Broker-aware required margin
- Daily profit targets
- Session-separated basket management
- Carry-over trade management
- Automatic basket profit closing
- Responsive and manually scalable chart panel
- Multi-chart synchronization
